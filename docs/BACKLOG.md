## Make all the art look like real video game sprites

**Added:** 2026-11-08 by Jenny.

Redo every picture in the game (characters, objects, backgrounds) as sprites
that look more like normal video game sprites.

- Each sprite should show clearly what it is for. Example: the **shy dino**
  in Level D should look very clearly shy.
- The game is for kids, so every picture must be easy to read at a glance.
  A player should know what each one means without reading any text.

Notes for when we start:
- Today all art is drawn from code (`scr_art_chars`, `scr_art_objects`), 16x16
  objects and 16x20 characters. A bigger sprite size or real sprite resources
  may be needed; decide that during planning.
- Keep the pixel look Jenny asked for, and keep Dot's chosen design (version 1).
